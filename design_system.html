VYBE Design System

Flutter 코드(lib/design_system/ · presentation/common/widgets/)에서 그대로 추출한 디자인 명세. 새 UI 작업 전 여기서 토큰·컴포넌트 존재 여부를 먼저 확인한다. 정의된 게 있으면 반드시 가져다 쓰고, 없을 때만 하드코딩.

CLAUDE.md Design System Rules 요약

DO
  • · 새 UI 전에 VybeColors · VybeTypography · common/widgets/ 먼저 확인
  • · 정의된 토큰/컴포넌트가 있으면 반드시 가져다 쓴다
  • · 모든 수치는 .w .h .r .sp
  • · 하단 알림은 VybeToast
  • · 재사용되는 UI는 common/widgets/에 Vybe prefix로 분리
  • · 디자인과 다르게 구현하면 사유를 주석으로 남긴다
DON'T
  • · 고정 px (width: 100) 사용 금지
  • · SnackBar 사용 금지 — 하단 탭바에 가림
  • · NestedScrollView.headerSliverBuilder에 pinned SliverPersistentHeader 금지
  • · VybeRecommendBadge의 색·모양·문구 변경 금지 (size만 조절)
  • · Widget 안에 비즈니스 로직 작성 금지
  • · presentation 레이어에서 Firebase import 금지
토큰이 없을 때 — VybeColors/VybeTypography에 없으면 하드코딩 허용. 단, 두 곳 이상에서 같은 값을 쓰게 되면 그때 토큰으로 승격시킬 것.
