Cloud Functions (13)

functions/src/index.ts — auth 7 · favorites 2 · reviews 3 · performances 1.

onCall — 앱이 직접 호출

  • naverLogin · kakaoLogin · phoneLogin → { customToken, isNewUser }
  • checkPhoneDuplicate → { isDuplicate }
  • verifyIdentity → { verified }, phone·birthDate 저장
  • deleteUser → Auth + Firestore + Storage 일괄 삭제

자동 트리거

  • onUserCreated — users/{uid} 자동 생성 (중복 실행 방어)
  • onFavoriteCreated / Deleted — favoriteCount ±1
  • onReviewCreated / Deleted / Updated — ratingSum · reviewCount · rating 재계산

스케줄 (Blaze 필요)

  • cleanupPastPerformances — 매일 KST 04:00
  • startAt < now - 8h 인 공연만 삭제 → 새벽 진행 중 공연 보존
  • 500개씩 배치 삭제
favorites 문서 생성
onFavoriteCreated
FieldValue.increment(1)
clubs.favoriteCount
앱은 읽기만
집계 필드(favoriteCount · ratingSum · reviewCount · rating)는 Cloud Functions 로만 갱신. performances 는 집계가 없어 트리거 불필요 — live/lineup 은 클라이언트에서 오늘 공연을 clubId 로 머지해 계산.

Firestore 컬렉션 · Storage

경로용도읽기 / 쓰기소비 화면
users/{uid}프로필 · phone · isVerified본인만 / 본인만마이페이지 · 인증
clubs/{clubId}클럽 본문 · location.geohash · 집계 필드누구나(isActive) / 어드민전 화면
clubs/…/info지하철 · 오픈챗 · 유의사항누구나 / 어드민상세 · 매장 정보 탭
clubs/…/menus메뉴 · 가격 · 대표 메뉴누구나 / 어드민상세 · 메뉴 탭
clubs/…/photosvenue / food / inside 분류 사진누구나 / 본인·어드민상세 · 사진 탭
clubs/…/reviews별점 · 본문 · 이미지누구나 / 본인·어드민상세 · 리뷰 탭
{path=**}/reviewscollectionGroup — 내 리뷰본인 리뷰만 / 불가MyReviewsScreen
favorites/{id}userId + clubId본인만 / 본인만찜 탭 · 찜 버튼
users/…/searchHistory최근 검색어본인만 / 본인만검색
banners/{id}홈 배너 · order · 노출 기간누구나홈
vybeRecommendationsrank · match · reason (에디토리얼)누구나VYBE 추천
performancestop-level · (클럽 × 날짜 × 공연)누구나힙합 · 공연 일정

필요한 인덱스

  • reviews COLLECTION_GROUP (userId ASC, createdAt DESC)
  • performances (genre, date, startAt)
  • clubs geohash 범위 쿼리 (location.geohash)

Storage 경로

  • clubs/{id}/thumbnail.jpeg
  • clubs/{id}/gallery/{n}.jpg — hero + 사진탭 공용
  • clubs/{id}/menus/… · menus/boards/…
  • reviews/{clubId}/{reviewId}/…
  • users/{uid}/profile.jpg

Rules 요약

  • clubs/** 공개 읽기, 어드민만 쓰기(10MB·이미지)
  • reviews/** 로그인 유저 업로드
  • users/{uid}/** 본인만 (5MB)
  • 어드민 = request.auth.token.admin == true
