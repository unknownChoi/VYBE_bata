USERS users/{uid}
필드명타입키설명
uidstringPKFirebase Auth에서 발급된 고유 사용자 ID
namestring사용자 실명
phonestring전화번호 (본인인증 완료된 번호)
birthDatestring생년월일 (YYYYMMDD 형식)
profileImageUrlstring프로필 이미지 URL — Storage 경로: users/{uid}/profile.jpg
providerstring로그인 제공자 (kakao / naver / apple)
createdAttimestamp계정 생성 시각
updatedAttimestamp마지막 프로필 수정 시각
CLUBS clubs/{clubId}
필드명타입키설명
clubIdstringPK클럽 고유 ID (Firestore 자동 생성)
namestring클럽 이름
descriptionstring클럽 소개글
addressstring클럽 주소
phonestring클럽 연락처
instagramUrlstring인스타그램 계정 URL
locationobject위도/경도 객체 { lat, lng }
geohashstring내 주변 GeoQuery용 위치 해시값 (geofire-common 라이브러리 활용)
imageUrlsarray클럽 상세 이미지 URL 목록 — Storage 경로: clubs/{clubId}/images/{index}.jpg
thumbnailUrlstring대표 이미지 URL — Storage 경로: clubs/{clubId}/thumbnail.jpg
tagsarray클럽 태그 목록 (예: 힙합, 루프탑 등)
favoriteCountnumber찜 수 — 찜 추가/취소 시 Cloud Functions가 자동으로 +1 / -1 업데이트
ratingAvgnumber클럽 평균 별점 (1.0 ~ 5.0) — 리뷰 추가/수정/삭제 시 Cloud Functions가 자동 업데이트
ratingCountnumber리뷰 총 개수 — ratingAvg 계산 기준
isActiveboolean클럽 활성 여부 (false 시 앱에 노출 안 됨)
isVybeRecommendedbooleanVYBE 추천 클럽 여부 — true 시 클럽명 옆에 👑 VYBE 추천 클럽 배지 표시
createdAttimestamp클럽 등록 시각
updatedAttimestamp클럽 정보 마지막 수정 시각
CLUBS_INFO clubs/{clubId}/info/{clubId}
필드명타입키설명
clubIdstringPK상위 클럽 ID (CLUBS와 동일)
operatingHoursstring영업시간 (예: 매일 22:00 ~ 05:00)
snsarray추가 SNS 링크 목록
updatedAttimestamp정보 마지막 수정 시각
PHOTOS clubs/{clubId}/photos/{photoId}
필드명타입키설명
photoIdstringPK사진 고유 ID (Firestore 자동 생성)
clubIdstringFK소속 클럽 ID (CLUBS 참조)
userIdstringFK업로드한 유저 UID (USERS 참조)
imageUrlstring사진 URL — Storage 경로: clubs/{clubId}/photos/{photoId}.jpg
categorystring사진 카테고리 (업체 / 음식 / 내부) — 전체 탭은 필터 없이 전체 조회
createdAttimestamp업로드 시각
MENUS clubs/{clubId}/menus/{menuId}
필드명타입키설명
menuIdstringPK메뉴 고유 ID
clubIdstringFK소속 클럽 ID (CLUBS 참조)
namestring메뉴명
descriptionstring메뉴 설명
pricenumber메뉴 가격 (원 단위)
imageUrlstring메뉴 이미지 URL — Storage 경로: clubs/{clubId}/menus/{menuId}.jpg
categorystring메뉴 카테고리 (예: 주류, 음식 등)
isAvailableboolean현재 판매 여부
createdAttimestamp메뉴 등록 시각
REVIEWS clubs/{clubId}/reviews/{reviewId}
필드명타입키설명
reviewIdstringPK리뷰 고유 ID
clubIdstringFK리뷰 대상 클럽 ID (CLUBS 참조)
userIdstringFK작성자 UID (USERS 참조)
ratingnumber별점 (1 ~ 5)
contentstring리뷰 텍스트 내용
imageUrlsarray첨부 이미지 URL 목록 — Storage 경로: clubs/{clubId}/reviews/{reviewId}/{index}.jpg
createdAttimestamp리뷰 작성 시각
updatedAttimestamp리뷰 마지막 수정 시각
FAVORITES favorites/{favoriteId}
필드명타입키설명
favoriteIdstringPK찜 고유 ID
userIdstringFK찜한 사용자 UID (USERS 참조)
clubIdstringFK찜한 클럽 ID (CLUBS 참조) — clubs.favoriteCount 자동 연동
createdAttimestamp찜 추가 시각
SEARCH_HISTORY users/{uid}/searchHistory/{historyId}
필드명타입키설명
historyIdstringPK검색 기록 고유 ID
userIdstringFK검색한 사용자 UID (USERS 참조)
keywordstring검색어
createdAttimestamp검색 시각
BANNERS banners/{bannerId}
필드명타입키설명
bannerIdstringPK배너 고유 ID (Firestore 자동 생성)
imageUrlstring배너 이미지 URL (텍스트 포함) — Storage 경로: banners/{bannerId}.jpg
linkTypestring클릭 시 이동 타입 (club / screen / url)
linkValuestringlinkType이 club이면 clubId, screen이면 스크린명, url이면 외부 링크
ordernumber슬라이드 노출 순서 (오름차순 정렬)
isActiveboolean배너 노출 여부 — 관리자가 직접 제어
startAttimestamp배너 노출 시작일
endAttimestamp배너 노출 종료일
createdAttimestamp배너 등록 시각
범례 PK  Primary Key — 문서 고유 식별자 FK  Foreign Key — 다른 컬렉션 문서 참조
