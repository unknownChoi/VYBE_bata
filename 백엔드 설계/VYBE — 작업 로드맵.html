Cloud Functions 구현 Claude 작성

인증 플로우의 핵심. 이것 없이는 카카오/네이버 로그인이 실제로 작동하지 않음.

  • kakaoLogin — accessToken → 카카오ID → Custom Token
  • naverLogin — accessToken → 네이버ID → Custom Token
  • verifyIdentity — PASS 본인인증 연동
  • deleteUser — 회원탈퇴 일괄 처리
  • onUserCreated — 신규 유저 Firestore 문서 자동 생성
  • onFavoriteCreated — favoriteCount +1
  • onFavoriteDeleted — favoriteCount -1

Security Rules 작성 및 배포 Claude 작성 + Justin 배포

Firestore와 Storage 보안 규칙. 배포 전까지는 테스트 모드로 진행.

  • Firestore — users, clubs, reviews, favorites, searchHistory
  • Storage — clubs/**, reviews/**, users/**
  • 어드민 Custom Claim 설정 (본인 UID에 admin: true 부여)

Flutter 데이터 레이어 구현 Claude 작성

인증 플로우 실제 연결 Claude 작성 + Justin SDK 설정

  • .env 파일 구성 — Flutter / Cloud Functions 키 세팅 (dotenv)
  • 카카오 SDK 연동 → accessToken → kakaoLogin Cloud Function 호출
  • 네이버 SDK 연동 → accessToken → naverLogin Cloud Function 호출
  • 본인인증 로그인 → verifyIdentity 호출 → 신규 유저 등록
  • 신규/기존 유저 분기 처리 (Firestore users/{uid} 존재 여부 확인)
  • Apple 로그인 — 이후 구현 예정
